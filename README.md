# Arduino Bluetooth Robot Arm

Projekt ramienia robota sterowanego za pomocą aplikacji mobilnej przez moduł Bluetooth.

### Wyprowadzenia pinów (Pinout):
* **Pin 8** – Serwo Łapy (Chwytak)
* **Pin 9** – Serwo Prawego Ramienia
* **Pin 10** – Serwo Lewego Ramienia
* **Pin 11** – Serwo Podstawy (Obrót)
* **Pin 6** – Arduino RX (połączone z TXD modułu Bluetooth)
* **Pin 7** – Arduino TX (połączone z RXD modułu Bluetooth)
